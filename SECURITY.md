# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in this project, please report it by opening an issue on GitHub or contacting us directly at our support email. We take security seriously and will address any issues promptly.

## Supported Versions

We support the following stable versions of this software:
- Version 1.0.0
- Version 1.1.0
- Version 2.0.0

Please ensure that you are running a supported version to receive security updates and patches.
